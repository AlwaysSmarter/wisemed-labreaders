Lifotronic H8

Configurare LIS ASTM prin rețea pentru readerul WiseMED. IP-urile vizibile în capturi sunt exemple; folosește adresele rețelei locale.

ASTMTCP/IPPort 8000

1. Deschide pagina LIS

  1. Din ecranul principal apasă System.
  2. În meniul lateral deschide Settings.
  3. Derulează până la secțiunea LIS.
  4. Activează LIS Upgrade și ASTM, ca în captură.

2. Configurează rețeaua

  1. Setează Local IP, Gateway și Netmask pentru analizor.
  2. La Server IP introdu IP-ul calculatorului pe care rulează readerul WiseMED.
  3. La Service IP Port introdu 8000, identic cu modules.transport-tcpip.port.
  4. Folosește Network Test dacă este disponibil, apoi salvează setările.
Server IP nu este IP-ul analizorului. Este IP-ul calculatorului/readerului care ascultă mesajele ASTM.

3. Trimiterea rezultatelor

  1. După finalizarea unei probe, deschide Result.
  2. Verifică rezultatul în lista aparatului și păstrează LIS/ASTM active.
  3. Faceți o probă de transmitere și verificați în WiseMED Logs apariția PARSED ASTM PACKAGE și asocierea rezultatului cu ID-ul probei.

Capturile documentează ecranul Results, dar nu arată un buton separat de Send. Dacă firmware-ul solicită validare manuală, validați rezultatul din ecranul Result și reluați testul de transmitere.
