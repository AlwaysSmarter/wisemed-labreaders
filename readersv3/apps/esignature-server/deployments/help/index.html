eSignature server

Utilitar Signotec Omega / Evolis Sig200. Setări pad · Demo (după login) · Server și update-uri

În administrare se configurează HTTP/HTTPS, originile web permise, conectarea WiseMED și update-urile, folosind aceleași componente ca barcodeprinter.

Update server: App ID esignature-server, OS windows, arhitectură 386, canal stable. Kitul conține STPadLib.dll x86.

API local: wss://localhost:19111/ws. Comenzi JSON cu id și action: health, devices, start, retry, confirm, cancel. Confirmarea returnează PNG base64. Captura este exclusivă, iar deconectarea și timeout-ul eliberează pad-ul.

Certificatul este gestionat de local-http. Driverele USB Signotec trebuie instalate separat. Testarea hardware se face pe Windows. DLL-ul Windows nu poate comunica cu USB din macOS/Linux.

CLI: -headless, -installservice, -showlog, -version, -config, -reconfigure. Nu porniți serverul Signotec simultan cu acest utilitar.

Integrarea WiseMED veche trimite cmd:init/signpatient. Confirmarea se face pe pad sau automat după 3 secunde fără puncte noi. Reia șterge semnătura și oprește numărătoarea. Răspunsul conține imaginea centrată 500×150 și sigenc în formatul Topaz SigString folosit de vechiul C#, fără configurare suplimentară. Suportul hardware Topaz va fi adăugat separat.
