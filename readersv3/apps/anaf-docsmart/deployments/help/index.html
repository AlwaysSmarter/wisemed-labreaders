ANAF DocSmart

Utilitar local pentru vizualizarea fișierelor XML DocSmart parse din sistemul de fișiere.

Flux

  1. Pune XML-urile în directorul configurat la transport-file.import_dir.
  2. Autentifică-te în interfața locală cu contul WiseMED.
  3. Deschide pagina Fisiere parse.
  4. Aplicația citește XML-urile și afișează metadatele parse din directoarele inbox, processed și failed.

Câmpuri afișate

CâmpDescriere
Nume fișierNumele fișierului XML găsit pe disc.
Starepending, processed sau failed, în funcție de director.
InstituțieValoarea atributului nume_ip din rădăcina XML.
Data documentValoarea atributului data_document.
Total debit / creditTotaluri calculate din nodurile cont.

Config principal

modules:
  transport-file:
    import_dir: ./inbox
    processed_dir: ./processed
    failed_dir: ./failed
    export_dir: ./outbox
    pattern: "*.xml"
