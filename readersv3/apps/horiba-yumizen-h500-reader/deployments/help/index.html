HORIBA Yumizen H500

Configurare LIS prin rețea pentru readerul WiseMED ASTM. Adresele IP din capturi sunt exemple și trebuie înlocuite cu IP-ul readerului din laborator.

ASTMTCP/IPPort 5150

1. Deschide configurarea LIS

  1. Autentifică-te cu utilizatorul tehnic și deschide Settings.
  2. În arbore: Results Settings → General → LIS Connection.
  3. Activează LIS Connection = Yes.
  4. Pentru acest reader selectează Network, nu RS232.
Capturile arată și pagina RS232. Ea este alternativă a aparatului; configurația WiseMED Yumizen H500 este TCP/IP.

2. Configurează rețeaua

  1. La Host Settings, completează Host IP cu adresa calculatorului pe care rulează readerul.
  2. Setează Port number = 5150, identic cu modules.transport-tcpip.port.
  3. În Analyzer Settings, folosește IP static, mască și gateway corespunzătoare rețelei locale.
  4. Salvează cu bifa verde și verifică Ethernet.

3. Trimite rezultate către LIS

  1. Deschide lista de rezultate și aplică filtrul dorit.
  2. Selectează rezultatele care trebuie expediate.
  3. Folosește acțiunea de print/transmit din ecranul Results.
  4. În dialog selectează opțiunea de trimitere a rezultatelor selectate și confirmă cu bifa verde.

Denumirea exactă a butonului poate diferi între versiuni de firmware; capturile arată dialogul cu opțiunile de tipărire și transmitere.
