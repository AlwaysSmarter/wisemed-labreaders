Căutare servicii

    

    Medicamente și compensări
    DCI, forme, concentrații, ambalaje, prețuri și liste de compensare. Medicamentele incluse în CLIN se importă împreună cu serviciile; nu necesită un import PHM separat. În Explorator API selectează sursa CLIN pentru aceste medicamente.
    Caută medicamente în Explorator API → · Liste de compensare și prețuri →
    

    Medici CNAS și OPSNAJ
    Nume, parafă, specialități, contracte și case de asigurări. Importă arhiva getPhysicianCatalogues cu tipul PHYS; cele două surse devin disponibile împreună.
    Caută medici → · Medici și contracte în rânduri plate →
    Toate nomenclatoarele din sursă
