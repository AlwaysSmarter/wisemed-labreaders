Biblioteci și terminal

Ordinea este aplicată după repornire. Fallback doar înainte de interacțiunea PIN, pentru erori de citire/compatibilitate; fără repetarea semnărilor sau scrierilor.

Contract și pacient

Pentru CNP vid sau 0000000000000 pe card, CID-ul este obligatoriu. Un CNP normal diferit oprește semnarea.
