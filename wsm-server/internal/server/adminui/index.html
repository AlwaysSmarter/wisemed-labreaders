Echipament creat
În reader: Settings → Debug WSS, autentificare Cheie echipament (JWT), apoi completează câmpurile de mai jos. Lipește cheia în câmpul Cheie WSS și apasă Salvează și aplică. Câmpul Fișier cheie este o alternativă opțională și primește o cale, nu cheia.
